NorthNode Outreach

Privacy Policy

Last updated: November 2026

This Privacy Policy describes how NorthNode Technologies ("we", "us", "our") handles information when team members use the NorthNode Educator Outreach platform ("the App"). This is an internal tool, not a public product.

1. What data we access via Google OAuth

When a team member connects their Gmail account, we request the following Google scopes:

  • gmail.send — To send outreach emails on behalf of the connected account.
  • openid, email, profile — To identify the connected account's email address and display name within the App.

We do not request access to read, delete, or modify emails. We do not access your inbox content.

2. How we store your data

  • OAuth refresh tokens are encrypted at rest using AES-256 symmetric encryption via PostgreSQL pgcrypto.
  • Tokens are stored in a Supabase-hosted PostgreSQL database accessible only to authorized team members.
  • No Gmail credentials or passwords are ever stored.

3. How we use Google user data

Google user data (OAuth tokens and account email) is used exclusively to:

  • Send outreach emails through the connected Gmail account via the Gmail API.
  • Display the connected account's email address within the App interface.

We do not sell, share, transfer, or use Google user data for any purpose other than operating the outreach sending function described above. This complies with Google's Limited Use requirements.

4. Data retention

OAuth tokens are retained until a team member explicitly disconnects their Gmail account from the App, at which point the token is deleted from our database. Team members may also revoke access at any time via Google Account Permissions.

5. Third-party services

  • Google Gmail API — For sending emails. Subject to Google's Privacy Policy.
  • Supabase — Database and backend infrastructure hosted in AWS ap-southeast-2.
